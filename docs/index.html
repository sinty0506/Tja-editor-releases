追加の指定

狙いがある項目だけ調整してください。閉じても指定は適用されます。「すべてデフォルトに戻す」で基本項目を含めて戻せます。

リズム・展開・配色の指定

主体にしたい方針を指定します。音取りは歌や楽器の推定です。音のない位置を埋める指定ではありません。許可リズム・密度上限・固定配色は下の設定で独立して指定できます。

コンセプトの詳細

「自動」は既存のリズム判別、「優先」は指定を重視、「厳格」は候補の細分を制限します。12分厳格は標準で12分主体＋24分装飾。必要な細分を既存設定で許可していない場合は生成前に知らせます。音源に合う候補がなければ疎な結果になります。

ジャンルを自動識別する機能ではありません。アドリブも検出した独立発音の範囲だけで選びます。未知曲での聴感・演奏感は確認が必要です。

整数tick、開始順、区間の重複なし。endTickは区間に含みません。例：[{"startTick":0,"endTick":768,"override":{"sourceFocus":"selective"}}]

リズムと密度の上限
自動判別で使用するリズム

上限を超える近接打は間引き、埋め直しはしません。既存ノーツ・連打・風船は配色比率の対象外です。打音1つでは比率を満たせません。

複合と曲の展開

GOGOでも音のない場所は埋めません。低密度ではキックを規則的に間引くため、目標密度を下回る場合があります。変奏0%では同じリズムのモチーフを揃えます。

大音符・連打・音程の配色

大音符は周囲の発音より音圧が明確に大きい箇所から、目安の割合を上限に選びます。該当する強音がなければ増やしません。連打・風船は短い連続打音から選びます。主旋律は前後の音程で配色し、低音・高音の境界を優先します。

主旋律には歌と楽器を含みます。★は複合・負荷の生成方針の目安です。曲のLEVELや、選んだリズム・密度上限は変更しません。
前回の生成結果・品質の目安

平均密度は生成範囲全体。最大1／2／5／10秒は各区間の打数÷秒数。P95は1秒窓・0.25秒刻みです。運手・負荷は推定です。★や楽しさを保証する評価ではありません。音を確認しながら編集してください。

操作ガイド

OpenTaiko v0.6.0.108向け譜面を、安全に作成・確認・書き出すためのガイドです。

最初の1曲を作る

  1. 新規プロジェクト音源を選び、曲名・BPM・OFFSET・LEVELを入力します。既存譜面は「TJAを開く…」の「TJA＋音源をまとめて選択…」で2ファイルを同時に選べます。
  2. プロジェクト情報「曲情報」からTITLE、SUBTITLE、GENRE、基本BPM、OFFSETを調整し、「変更を適用」で確定します。デスクトップでは左下の「曲情報・基本設定」からも開けます。
  3. 譜面を編集左のノーツまたはEVENTを選び、対応するタイムラインをクリック／ドラッグします。小節線は専用レーンで編集します。
  4. 音と動きを確認再生、プレビュー、比較プレビュー、メトロノームを使ってタイミングを確認します。
  5. 保存して書き出す.tjaprojを保存してから「書き出し…」で.tjaと.oggを同じフォルダーへ出力します。
大切なこと

.tjaprojが編集用の正本です。.tjaは書き出し成果物なので、作業中はこまめにプロジェクトを保存してください。

PC音声から作成する

新規作成の音源選択の下にある「PCの音を録音」で、Windowsの既定の出力から流れる音を録音できます。もう一度押すと停止し、前後の完全な無音をカットしたWAVが音源に設定されます。静かな余韻と曲中の無音は残します。最大30分で、マイクは含みません。キャンセルやEscで未確定の録音を破棄できます。ウィンドウ単位の音声分離には対応していません。

音源編集

自動採譜の「譜面コンセプト」では、音取り・リズム・展開・配色を別々に選べます。「12分主体」を選び、詳細の指定を「厳格」にすると、標準では12分の骨格と局所的な24分装飾から選び、16分主体へ切り替えません。必要な12分を既存の許可リズムでも選んでください。「優先」では音に根拠のある別系統も許容します。16分主体＋32分アクセントでは既存側の32分許可も必要で、瞬間密度上限は引き続き守ります。音が不足しても埋めず、生成結果の「コンセプト適合」に実間隔比率・未達理由・配色役割の変更を表示します。詳細の実験設定は初期OFFです。「すべてデフォルトに戻す」はコンセプトもまとめて戻します。

上部の「自動採譜」では、拾う音ごとのドン／カッ／自動／除外、メロディーと伴奏の重視度、密度、音取りと楽しさの重視度を指定できます。主旋律には歌声と楽器の両方を含みます。「キックの等間隔リズムを優先する」は、検出したキックの周期を保ち、低密度では均等な間引きを優先します。音のない位置にキックを足す機能ではありません。詳細を閉じていても、使用リズム・打速上限・GOGO・大音符・連打・風船の設定値を見出しで確認できます。

「瞬間密度の上限」「連打を使う」「風船を使う」は追加の指定を開かずに操作できます。「大音符の目安」は割合の上限です。大音符は音源の短時間RMSを周囲の発音と比較し、明確に大きい強音で、密集し過ぎない位置を選びます。小節頭という理由だけでは大音符にしません。連打は短い連続打音、風船は盛り上がる連続打音が候補です。再生成時は対象範囲の打音・連打・風船を一から作り直します。選択範囲のみ生成では、範囲外と境界をまたぐ連打・風船を保持します。

「生成して反映」で選択中の難易度・分岐へすぐ反映し、Ctrl+Zで採譜前に戻せます。メロディーは前後の音高で配色し、設定した高音はカッ、低音はドンを優先します。主旋律・打楽器や音高の判別は推定です。完全な音源分離ではないため、実曲では試聴しながら調整してください。音のずれが続く場合は、先にBPM・OFFSETを合わせてください。

「範囲選択」で選んだ範囲がある場合、その範囲内だけを生成・置換し、範囲外のノーツを保持します。採譜画面に秒数を表示します。曲全体を採譜する場合は、先にEscで範囲を解除してください。

配置グリッドの「自動」は、チェックしたリズムだけから推定します。「16分＋24分だけ」「12分＋16分だけ」でまとめて選べます。初期状態では32分・48分を使いません。「似たフレーズのリズムを揃える」が有効な時は、小節をまたぐ最大32拍をまとめて評価し、曖昧な候補による細分の切替を抑えます。明確な三連符は切り替え、空の拍・選択範囲・編集できない区間・既存ロングで評価を区切ります。近くの似た小節で同じ位置・音の種類が繰り返される候補を少し優先し、再打音の根拠が弱い帯域補助検出の連続候補は優先度を下げます。固定12分を含む手動グリッドも選べます。

「瞬間密度の上限」はノーツ間の実時間で近接打を制限します。初期値は基本BPMの16分相当で、上限は48分相当です。4・8・12・16・24・32・48分の目盛りを表示します。BPMが高い時や拍・小節の境界でも実時間の間隔を守ります。新しい打音は保持する既存打音との間隔も確認し、既存ノーツ自体は動かしません。間引いた分を平均密度のために埋め戻すことはありません。制限は生成する通常打音に適用し、既存の密集配置を自動修正する機能ではありません。

配色の70%補正は生成した通常打音全体に適用し、連打・風船や既存ノーツは数えません。ドンのみの導入などは残せますが、比率を満たすために必要な場合は、音色指定やメロディーの色も補正します。音色指定を最優先にしたい時はチェックを外せます。打音1つでは7:3以下を満たせません。生成後に間引き・配色補正・アレンジの打数を表示します。

基本設定で難易度の目安・密度・拾う音を決め、必要な詳細だけ開いて調整できます。「複合と曲の展開」では、反復の変奏量・体力負荷・配置済みGOGOの密度強調を指定します。GOGOでも無音は埋めません。通常は検出した音だけから選び、補助ノーツを有効にした場合だけ活動中の短い打音間を16分でつなぎます。

複合の配色を任せたい打音は「自動」を選んでください。最大2小節のまとまりと反復を使って候補を比較します。生成後に再び開くと「前回の生成結果」で密度・運手・反復などの目安と処理時間を確認できます。同じ音源・音源編集なら解析を再利用します。★や評価値は推定であり、試し叩きで確認してください。

結果の最大1／2／5／10秒密度は、それぞれの長さの区間にある打音数を秒数で割った値です。瞬間密度の上限（隣接打音の間隔）とは別に確認できます。「候補・配色の判断を記録する」を有効にして生成すると、結果内に採用・棄却や音色指定・音程・配色補正の理由をJSONで表示します。詳細は最大12,000件で、理由別の件数は全件分です。初期状態はOFF、原音声やファイルパスは含めず、保存や送信は行いません。

音源編集は右側のタブで切替できます。「テンポ・音程・EQ」では音程を保つ0.5～2倍のテンポ変更、独立した±12半音の音程、3帯域EQ、プリセット、ピーク音量調整を行えます。「曲をつなぐ」では追加音源の範囲・テンポ・クロスフェードを設定し、つなぎを試聴してから新しいWAV音源として適用します。元のファイルは保持し、接続もCtrl+Zで戻せます。音源の長さを変えてもノーツの時刻は自動移動しません。

音源編集の「全体を選択」は現在のトリム開始～終了を選びます。「選択解除」は範囲だけを解除し、「選択範囲を拡大」は選択した箇所へ表示を合わせます。これらは音源や編集履歴を変更しません。1ms/10msの境界調整は「境界を微調整」を開きます。「変更を適用して戻る」で編集を確定します。

「原音と比較」で編集前を試聴でき、「選択範囲をループ」で同じ箇所を繰り返して調整できます。通常の音源編集は「変更を適用」で確定します。

上部の「BPM」から自動BPM・OFFSET推定と前後の完全無音カットを開けます。候補一覧と½倍／2倍でテンポを選び、「BPMを適用」でBPMだけを反映できます。OFFSETやノーツの時刻は保持します。「従来の測定サイト」も利用できます。無音カットは譜面との対応を維持し、Ctrl+Zで戻せます。

OFFSETの下にある「小節の頭：1拍前へ／1拍後ろへ」は、先頭のBPMの四分音符1拍分、小節線をずらします。ノーツの時刻は変えず、Ctrl+Zで元に戻せます。

プレビュー下の速度で0.5～1倍に調整できます（スロー時は音程も変化）。「DEMOSTART / 試聴」では秒数、または何回目のゴーゴーかと前後1小節を指定して試聴できます。「試し叩き…」はWindows版で別ウィンドウを開きます。Spaceで開始し、設定済みのドン／カッキーや左のパッドで叩けます。達成率、良・可・不可、連打数、×表示、オート、速度、判定調整をまとめています。正の判定調整は入力を早めます。← →キーや帯のドラッグで開始小節を選択し、Escで閉じます。

ノーツ数は連打・風船を除いた打音の数です。平均密度は「（打音数−1）÷最初の打音から最後の打音までの秒数」で、打音が0個・1個の場合は0です。上部の「書き出し…」の右隣にある「譜面画像…」で、表示中の難易度・分岐ルートをTJA Tools形式のPNGに出力できます。

譜面画像にはTJA Tools（Snack、MIT License）の描画処理とPixel 3x5フォントを使用しています。通常はサイトと同じ16拍単位の折り返しで1枚の画像を保存します。

WAV、MP3、Ogg Vorbis、音声入りMP4／MKVを読み込めます。MP4／MKVは映像を保存せず、抽出した音声だけを管理します。

TJAを開くとき

TJAを選択した後、「特殊な間隔の配置」で「グリッドに丸める」か「丸めずに保持する（内部小節線）」を選べます。丸めない方式では元の配置時刻を保存・再読込・書き出しでも保持し、内部小節線は演奏画面に表示しません。エディターで保持できない命令が見つかると、対象機能を列挙して確認します。続行した場合、その部分だけを省略して開きます。元のTJAは変更しません。

Androidの保存先

プロジェクトは Documents/TJA Editor/Projects、書き出しは Documents/TJA Editor/Exports に保存します。外部から開いた.tjaprojの隣接音源はAndroidの権限制約で自動取得できないため、求められた場合は音源を選び直してください。
